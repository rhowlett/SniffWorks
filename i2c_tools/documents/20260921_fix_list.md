# ion_i2c_tool — Review: Gaps, Bugs, Consistency, Refactoring

Severity: H = wrong output / data loss, M = functional defect or friction, L = hygiene.

## 1. Missing vs. the product description

## 2. Bugs

| # | Sev | Issue | Recommended fix | Files |
|---|---|---|---|---|
| B1 | H | **(verified)** The decoder schema's `if` blocks lack `required`. A valid rule with no `format` key (for example a plain indexed_read) fails validation with "bit_fields is required". The subcommand and register conditionals have the same flaw. | Add `"required": ["format"]` or `["transaction_type"]` inside each `if`. | `schema/decoder.schema.json` |
| B2 | H | **(verified)** `DecodeSchema.to_json()` drops top-level metadata (`device`, `description`, `i2c_address*`, `byte_order_note`) on all three decoders. After a save, the Decoders list shows the filename instead of the device name. | Keep a `metadata` dict and pass unknown keys through on save. | `core/decode_schema.py` |
| B3 | M | **(verified)** A `bits` rule with an empty `bit_fields` list loses the key on save, and the saved file then fails the schema. Example: bq76922 "PF Alert D", reg 0x10, which is also marked "verify vs SLUUCG7". | Always emit `bit_fields` for `bits` rules, or set `minItems: 1` and fix the decoder. | `core/decode_schema.py`, `schema/decoder.schema.json`, `i2c_decoders/bq76922_decoder.json` |
| B4 | H | **Editor Add/Update rebuilds the rule from the form.** This silently wipes `description`, `fields`, `register_width_bytes`, subcommand data, and bit-field descriptions. `_collect_bit_fields` drops enum fields whose names contain commas: **(verified)** 13 fields in bq25731. Changing addr/reg/dir leaves the old rule behind as a duplicate. | Edit a copy of the selected rule (`dataclasses.replace`) and treat a key change as a move. Use a per-name table instead of a comma string. Surface parse errors instead of dropping fields. | `ui/widgets/decode_editor.py` |
| B5 | H | **Selecting or removing a subcommand row in the editor does nothing.** The key is derived from Dir+Reg (giving `simple_write`), not from `rule.key()`. | Store `rule.key()` in each row's `Qt.UserRole` and use it for find and remove. | `ui/widgets/decode_editor.py` |
| B6 | M | **The single-byte simple-write path is dead code.** `_is_pointer_write` is true for every 1-byte write, so `simple_write` rules never decode and the byte is stashed as a pending register. | Prefer a `simple_write` rule when the address has one and no indexed rule for that byte. Otherwise treat it as a pointer. | `core/decode_schema.py` |
| B7 | H | **The PEC check is wrong for combined transactions.** SMBus PEC covers Addr+W, command, Addr+R, and data. The code covers only the current phase, so every SMBus read-word or read-block shows ✗ PEC. | Compute PEC at the pairing layer (write phase + read phase), not per phase. | `core/i2c_controller.py` (`write_read`, `spy_poll`), `core/ion_backend.py`, `core/log_model.py` / `decode_schema.py` |
| B8 | H | **AD2 `spy_poll` discards continuation segments** (`fStart == 0`). Transactions split across status calls are truncated (for example 36-byte subcommand blocks), and stop-only status is lost. | Accumulate segments until Stop or Restart, following the Digilent `Digital_I2c_Spy.py` pattern. | `core/i2c_controller.py`, `core/spy_worker.py` |
| B9 | M | **The IonWorker drain on stop exits at the first empty read** (`timeout=0`), so the final frames are lost. | Loop until the deadline with a short sleep. | `core/ion_backend.py` |
| B10 | M | **IonMasterLink desyncs after a timeout.** Late TXN frames stay in `_pending` and are attributed to the next command. | Flush the parser and pending list before each send, or add a sequence tag in protocol v2. | `core/ion_master.py` (+ protocol files) |
| B11 | M | **The dashboard uses `.4g`,** so non-integer values ≥ 10,000 show in scientific notation (`1.235e+04`). This also differs from the log's formatting (`.4f`, stripped). | Use one shared value formatter for the log and dashboard. | `ui/widgets/registers_view.py`, `core/decode_schema.py` |
| B12 | M | **The bit matrix renders only 1–2 bytes.** Bit rules with `data_bytes ≥ 3` lose bits 16 and up. | Generate one row per byte for N bytes. | `ui/widgets/registers_view.py` |
| B13 | M | **The dashboard cache key includes `transaction_type`.** A write to an R/W register never updates the read row (bq25731 has 17 write rules). | Key the cache by (address, register) or link each read rule to its write rule. | `ui/widgets/registers_view.py`, `core/decode_schema.py` |
| B14 | M | **Register tabs filter the merged schema by `min(addresses)`.** Two decoders on the same address (bq76905 and bq76922, both 0x08) show each other's rules. `display_groups` are merged globally by name. | Build each view from its own entry's schema and namespace groups per device. | `ui/widgets/registers_tabs_host.py`, `core/decoder_manager.py` |
| B15 | M | **The expression evaluator can be DoS'd.** `**` and `<<` are unbounded (`X**X`, `1<<10**9`) and can hang the app. `min/max/round` with bad arguments raise `TypeError`, which escapes the `_render` error handling. | Cap exponent and shift sizes. Catch `TypeError`/`ValueError`/`OverflowError` and convert them to `DecodeError`. | `core/decode_schema.py` |
| B16 | M | **The AD2 self-test likely reads the wrong nodes.** Temperature and supply both read AnalogIO ch0/node0 (V+ enable), and temperature uses `NodeGet` instead of `Status`. The test always reports PASS. Verify against the WaveForms SDK sample; the USB monitor should be ch2. | Read the correct channel and nodes, and fail when a reading is `None`. | `core/device_manager.py` |
| B17 | M | **AD2 connect ignores the Device-tab settings.** It applies a hard-coded 100 kHz with ALERT off. Scan is allowed while the spy is running (it drives the bus during passive capture), and the scan Cancel button does nothing. | Apply the panel's values on connect. Disable Scan while sniffing and wire up Cancel. | `ui/sniffer_window.py` |
| B18 | M | **The Ion sniffer UI stays in the "running" state** when the worker exits on error (no HELLO, port lost). | On `disconnected`, reset SnifferPanel through a new `set_running(False)`. | `ui/sniffer_ion_window.py`, `ui/sniffer_panel.py` |
| B19 | H | **CSV export writes only filtered rows.** Re-importing drops pointer writes and breaks decode pairing. The time column is `HH:MM:SS.mmm`, so replay assumes today's date, midnight reorders rows, and device µs precision is lost. | Default to exporting all rows, with filtered export as an option. Use ISO 8601 with µs in the capture schema (M1). | `core/log_model.py`, `ui/log_panel.py`, `ui/common/capture.py` |
| B20 | M | **The master's NAK on the final read byte (normal I2C) is shown as an error** (red). NAK-based frame grouping in `_compute_visible` depends on this behavior. | Distinguish address NAK, data NAK, and end-of-read NAK, and adjust the grouping logic at the same time. | `core/log_model.py`, `core/i2c_controller.py`, `core/ion_backend.py` |
| B21 | L | **`subcommand_reg` defaults disagree.** The schema says it defaults to 62 (0x3E); the code treats a missing value as "no subcommands". | Pick one behavior and make the schema and code match. | `core/decode_schema.py`, `schema/decoder.schema.json` |

## 4. Refactoring for extensibility

| # | Issue | Recommended fix | Files |
|---|---|---|---|
| R1 | `SnifferWindow` and `SnifferIonWindow` duplicate the decoder wiring, stats, txn relay, close guard, and theme handling. | Add a `CaptureBackend` interface (start/stop/set_pec plus signals) with AD2, Ion, and HandTool implementations, and one `BaseSnifferWindow`. | new `core/backends/`, both sniffer windows, `spy_worker.py`, `ion_backend.py` |
| R2 | `I2CTransaction` lives in the ctypes AD2 module, and `ion_master` monkey-patches `timeout` and `result` onto it. | Move it to `core/transaction.py` with real fields. | `core/i2c_controller.py`, `ion_*`, `log_model.py`, `capture.py`, tests |
| R3 | Layering violations: `core/log_model` imports `ui.theme`, and capture I/O sits in `ui/common` with two separate row parsers. | Move capture I/O to `core/capture_io.py` with one parser. Put colors in a UI delegate. | `core/log_model.py`, `ui/common/capture.py`, `ui/log_panel.py` |
| R4 | The TI BQ769x subcommand protocol (0x3E echo, 36-byte frame, checksum, `sub_reg+2` buffer) is hard-coded in the generic engine. | Add a per-decoder `subcommand_protocol` block to the JSON so new devices need no code. | `core/decode_schema.py`, schema, decoders |
| R5 | Addresses are hard-coded per rule, so two identical ICs or strap-selectable addresses cannot be supported. | Add a file-level default address and a per-instance override in the manager. | `core/decoder_manager.py`, schema, `sidebar_sections.py` |
| R6 | `on_rule_decoded` is a single-observer attribute, and `multiline_bits` is mutable state on a shared schema. | Use a listener list or Qt signal, and pass render options per call. | `core/decode_schema.py`, `registers_view.py`, `log_model.py`, `replay_window.py` |
| R7 | Long-capture performance: `_subcommand_reg` scans all rules on every transaction. With a search active, each added row triggers a full model reset (O(n²)). Rows are resized and a signal is emitted per transaction. The log grows without bound. | Cache per address, filter incrementally, batch UI updates on a timer, and add an optional row cap. | `decode_schema.py`, `log_model.py`, `log_panel.py`, sniffer windows, `registers_view.py` |
| R8 | Code reaches into private members: `model._entries`, `model._visible`, `schema._render`. The `count - 3` tab insertion is hard-coded. | Expose public APIs and a tab insertion anchor. | `replay_window.py`, `log_panel.py`, `decode_editor.py`, `registers_tabs_host.py` |
| R9 | Test gaps: no CSV round trip, no editor round trip, no simple-write case, no combined PEC, no schema check on every decoder. The tests are script-style with no single runner. | Add these tests and a pytest runner. | `tests/` |
