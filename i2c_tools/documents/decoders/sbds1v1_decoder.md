# Smart Battery (SBDS v1.1) — I2C decoder

Smart Battery Data Specification v1.1 command set, spec only. Battery at 7-bit 0x0B (SMBus 3.3 Table 17); battery-master messages to the Charger (0x09) and Host (0x08). Sources: SBDS Rev 1.0 (functions, units, bits, error codes, protocols), errata_sbdat110a (v1.1 BatteryMode ALARM_MODE and SpecificationInfo codes), SBS 1.1 command tables (OptionalMfgFunction 0x2F, 0x3C-0x3F). Values are shown in base units: capacity/rate rules depend on BatteryMode CAPACITY_MODE and voltages/currents/capacities are further x 10^VScale / 10^IPScale per SpecificationInfo; the decoder applies neither. Words are LE. Reserved: 0x1D-0x1F, 0x24-0x2E, 0x30-0x3B, 0x40-0xFF; the upper two command bits are reserved for multi-battery addressing. Multi-address file (rules carry their own address). Generated by build_sbds_decoder.py.

- **Address:** 0x0B (8-bit W 0x16 / R 0x17)
- **File byte order:** le
- **Schema version:** 4  ·  **Rules:** 52
- **Note:** SMBus words: Data Byte Low first (SBDS 1.0 §6.1).

## Decode behaviour

- **Values are shown in base units and never rescaled.** Capacity and rate rules (0x01, 0x04, 0x0F, 0x10, 0x18) show `mAh/10mWh` or `mA/10mW`, because the unit depends on BatteryMode CAPACITY_MODE. Voltages, currents and capacities are also multiplied by 10^VScale / 10^IPScale from SpecificationInfo (ChargingCurrent/ChargingVoltage excepted). Read 0x03 and 0x1A to interpret them.
- **65535 invalid-data values** are shown as numbers; their meanings are in each rule description (not charging, not discharging, voltage/current source mode, ≥ 65535 cycles).
- **AlarmWarning** (battery as master) is decoded at the Charger (0x09) and Host (0x08) with the BatteryStatus bit map. Its error code bits are all set by definition, so 0xF shows "AlarmWarning (all set)". On a BatteryStatus *read*, 0x8–0xF show as reserved.
- **Neware conformance:** matches `documents/decoders/Smart Battery Registers.txt` on all 37 registers except two intentional, spec-governed access differences: 0x14/0x15 are read-only at the battery (SBDS App A), and 0x3C–0x3F are r/w OptionalMfgFunction (SBS 1.1). See `test_neware_doc_conformance.py`.
- **Block reads** decode the length byte; the text is in the capture's ASCII column.
- **Not decoded:** reserved codes 0x1D–0x1F, 0x24–0x2E, 0x30–0x3B, 0x40–0xFF. The upper two command bits are reserved for multi-battery addressing.
- **Multi-address file:** rules at 0x08, 0x09 and 0x0B. It has the same per-rule-address dependency as `smbus_reserved_decoder.json`.
- **Load set:** keys are disjoint from the four SMBus decoders and from `neware_decoder.json`. The 0x08 / command 0x16 rule moved here from `smbus_host_notify_decoder.json`.
