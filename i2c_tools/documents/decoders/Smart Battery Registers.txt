Bits 3:0 0x000F Error Code


The standard SBS error codes are:

Plain Text
0x0 OK
0x1 Busy
0x2 ReservedCommand
0x3 UnsupportedCommand
0x4 AccessDenied
0x5 Overflow/Underflow
0x6 BadSize
0x7 UnknownError
0x8-0xF Reserved
Show more lines

These codes are intended to report the outcome of the most recent SMBus transaction directed to the battery. The specification states that after a transaction, the battery places the appropriate error code into the lower nibble of BatteryStatus(), and successful transactions clear the error code back to OK (0x0).

A few practical notes:

ReservedCommand (0x2) means the host attempted to access a command code reserved for manufacturer use.
UnsupportedCommand (0x3) means the command is defined by SBS but not implemented by that battery.
AccessDenied (0x4) is typically returned when the operation is not permitted in the battery's current state.
BadSize (0x6) indicates an incorrect data length was supplied.
UnknownError (0x7) is a catch-all for errors that do not fit the other defined categories.

In practice, many modern fuel gauges (for example, several TI gauges) still use these SBS-defined values, which is why you will often see documentation referring to EC[3:0] as the SBS error code field.
